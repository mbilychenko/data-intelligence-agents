# AI Agents

A collection of Claude Code agents for engineering teams.

## Agents

| Agent | Description |
|---|---|
| [data-map-agent](data-map-agent/) | Helps analysts understand what data exists in production repos — where it lives, how it flows, how to access it |

## Usage

Each agent is a self-contained Claude Code workspace. Open the agent's folder in Claude Code to use it.

```
cd <agent-name>
claude
```
